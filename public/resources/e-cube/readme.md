<h1>信息学部 “E立方” 学风涵养工作室资料栈说明</h1>
<p>“E立方”  学风涵养工作室资料栈，
由信息学部  “E立方”  学风涵养工作室和HITSZ开源技术协会筹备与管理。
资料栈内容围绕工作室历年来开展的各类活动展开，
且分为创新创业、学业辅导、生涯规划这三大板块。</p>
<h2>🚀 创新创业板块</h2>
<p>该板块收纳了工作室举办的与创新创业相关活动的资料。
涵盖创新创业竞赛的组织策划方案，详细记录了竞赛的流程、规则和奖项设置；
参赛团队的精彩项目展示资料；
专家和同学分享讲座的资料，包括讲座视频、PPT等，这些讲座为同学们带来了前沿的创新创业理念和实践经验。</p>
<h2>📚 学业辅导板块</h2>
<p>这部分聚焦于学业方面的活动资料。
有针对不同课程的学习方法分享会资料，包括分享会的 PPT、文字记录，让你从中获取高效的学习技巧；
还有学业帮扶计划的相关课程录像，笔记，PPT等，记录了工作室如何帮助同学们解决学习困难，提升学业成绩。</p>
<h2>🗺️ 生涯规划板块</h2>
<p>此板块精心整合了一系列对同学们职业生涯规划具有重要指导意义的活动资料，从多个维度助力同学们明晰未来方向，为成长与发展提供有力支持。
其中，老师生涯规划讲座资料涵盖详细课件与音视频记录，老师凭借专业知识和行业经验，分析热门行业趋势，引导同学们规划职业路径；
港校分享会，邀请成功入读港校的学长学姐及专业人士，分享申请流程、教学模式等；
学长学姐经验分享资料形式多样，有现场录音和个人成长故事文档，涵盖学业规划、实习求职等经验；
“开学强心针” 活动资料包括策划方案、动员讲话文稿等，助力同学们新学期调整状态、明确目标；
“考前强心针” 讲座资料则有重点知识梳理、答题技巧指南及心理调适方法，帮助同学们缓解考试压力、提高复习效率。</p>
<h3>更新维护</h3>
<p>工作室会定期对资料栈进行整理和更新，确保资料的完整性和准确性，为大家呈现一个丰富、全面的工作室活动历史记录。</p>
