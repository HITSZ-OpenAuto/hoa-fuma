# 网站 URL 结构与 SEO 优化方案

审查日期：2026-09-24。依据当前仓库代码、内容文件和 `https://hoa.moe` 的线上响应。目标是让公开内容可以被搜索引擎抓取，并让每篇内容有清晰、稳定的首选 URL。

## 现状

| 项目     | 核查结果                                                                                                                                                                                           |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 主要路径 | 课程资料使用 `/docs/{年级}/{专业代码}/{学期}/{课程代码}`；博客和新闻分别使用 `/blog/...`、`/news/...`。层级与站内导航一致，无需整体改写。                                                          |
| 抓取权限 | `public/robots.txt` 的 `User-agent: *` 规则为 `Disallow: /`；线上文件相同。Googlebot 无法抓取公开页面内容。                                                                                        |
| 站点地图 | 线上 `/sitemap.xml` 返回 404；仓库中没有站点地图生成文件。                                                                                                                                         |
| 规范网址 | `app/layout.tsx` 设置了 `metadataBase`，但页面没有输出 `rel="canonical"`；站点地图也无法提供首选 URL 信号。                                                                                        |
| 重复内容 | `content/docs/` 有 20,859 个 Markdown/MDX 文件。其中 7,136 个长度超过 1,000 字节的文件与至少另一文件完全相同，分布在不同年级、专业或学期路径。该统计针对源文件，不能直接等同于最终 HTML 完全相同。 |
| 文档入口 | `app/docs/page.tsx` 根据 Cookie 把 `/docs` 临时重定向至历史页面或最新年级。线上无 Cookie 时返回 307 至 `/docs/2026`。                                                                              |
| 旧链接   | 内容中仍有旧地址。实测 `/blog/distributive-guidance-for-21/`、`/blog/writing-rules/` 去掉末尾斜杠后最终返回 404；`/docs/junior-spring/auto3007/` 经两次跳转才到有效页面。                          |
| 域名     | 线上 `http://hoa.moe` 和 `https://www.hoa.moe` 已通过 301 汇聚到 `https://hoa.moe`，继续以此作为唯一站点域名。                                                                                     |

## 实施顺序

### 1. 恢复公开页面的抓取

调整 `public/robots.txt`，允许 Googlebot 等常规搜索引擎抓取公开页面。保留现有针对特定爬虫的明确规则；只有确认不应被抓取的路径才单独限制。上线后检查线上 `robots.txt`，并使用 Google Search Console 的网址检查确认代表性博客、新闻和课程页可抓取。

这一项先于 canonical、站点地图和页面元数据：被 robots.txt 阻止的页面无法让 Google 读取这些信号。robots.txt 本身也不能保证 URL 不出现在搜索结果中。

### 2. 确定可收录 URL 与规范网址

以现有路由和内容源为准，列出首页、静态页、博客、新闻、标签页及课程资料页的正式 URL。独立页面输出指向自身的绝对 `rel="canonical"`，重复页面按下述规则指向首选 URL；域名统一为 `https://hoa.moe`，并与站点地图保持一致。

课程页只按课程号归组，比较时将课程号统一为大写，不再把年级、专业、学期或文件内容作为分组条件。当前 18,193 个四级课程源文件对应 2,048 个课程号。先排除没有实际资料的占位页后，剩余 7,546 个页面、152 个课程号；如果每个课程号只选择一个首选页面，其余 7,394 个路径会成为非首选 URL 候选。这是 URL 数量的计算，不代表搜索引擎已经合并这些页面。

`CHEM1018` 这类页面仅有课程信息和“暂未收录对应的 GitHub 仓库”固定提示，应继续返回 200 供学生查看培养方案，但输出 `noindex, follow`，并从站点地图排除。以现有内容中的占位模板为判断依据，不靠空 description 或字数推测。当前有 10,647 个此类四级课程页，涉及 1,896 个课程号，且这些课程号目前均没有实际资料页。如果以后同一课程号出现资料页，占位页仍不收录，首选 URL 从有实际资料的页面中选取。不要用 robots.txt 禁止抓取这些页面，否则搜索引擎无法读取 `noindex`。

对于剩余有实际资料的页面，每组选择年级最新、同一年级内路径按字典序最小的现有页面作为首选 URL。该页输出自指 canonical，其余页面保留 200 和原有年级、专业导航，但 canonical 指向此 URL；站点地图每个课程号只列首选页。通过现有内容源生成同一份课程号到首选路径的映射，供页面元数据、站点地图和无 Cookie 时的课程短链接跳转共用，不新增数据库或持久记录。`/docs/{课程号}` 目前会重定向，不作为 canonical 或站点地图 URL。若要让短链接本身出现在搜索结果中，需要另行把它改为对所有访问者返回相同内容的 200 页面。

这一规则会跨年级合并不同版本。实际资料页中有 34 个课程号对应多个页面标题，例如 `PE100X` 对应不同体育课名称。Google 的 canonical 用于重复或高度相似的页面；对于内容差异明显的页面，Google 可能不采用按课程号指定的首选 URL。上线前抽查这些课程号，并在 Search Console 核对 Google 实际选择的 canonical；单靠标签不能保证每个课程号最终只收录一个页面。

这一阶段处理搜索引擎面对的重复 URL，不删除源文件。课程文件由 `scripts/fetch-content.sh` 调用上游数据生成；若要消除文件存储中的重复，应另行调整上游生成方式。

暂不重命名专业代码、课程代码或全站 slug。这些路径承载现有导航和外部链接；在抓取与重复内容问题解决前，大规模迁移没有明确收益。

新闻中，`/news/weekly` 及其下所有周报页面、`/news/daily` 日报页面继续供站内阅读，但输出 `noindex, follow`，不列入站点地图。直接按现有新闻 slug 判断，不增加内容字段；未来新增的周报自动适用。当前 112 个新闻内容页中，周报 100 个（含周报首页）、日报 1 个，剩余 11 个其他新闻内容页继续作为收录候选。`/news` 新闻列表页不在这项排除范围内。

### 3. 发布站点地图

从现有页面与内容源生成 `/sitemap.xml`，只包含返回 200、允许抓取且被选为首选版本的绝对 URL。`/docs` 这类重定向入口、RSS、搜索 API、404 和重复页面不列入。只有能取得可靠的实际修改时间时才填写 `lastmod`。在 `robots.txt` 中加入站点地图地址，并提交至 Google Search Console。

### 4. 修正内容源中的旧链接

已确认的旧地址与目标地址如下，两处新地址均已在线返回 200：

| 旧地址                               | 目标地址                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------- |
| `/blog/distributive-guidance-for-21` | `https://hoa.moe/blog/course-selection-auto/distributive-guidance-for-21` |
| `/blog/writing-rules`                | `https://wiki.hoa.moe/`                                                   |

博客文章中的旧地址在上游 [hoa-blog](https://github.com/HITSZ-OpenAuto/hoa-blog) 直接改为目标地址；新闻与生成的课程内容在抓取后修正引用。此次不新增旧博客地址重定向；旧地址继续返回 404。第二条是跨域链接，目标域名由已确认的新链接决定。

博客中的课程引用应按文章适用的培养方案，直接指向 `/docs/{年级}/{专业}/{学期}/{课程号}`。例如 21 级自动化指南中的过程控制系统指向 `/docs/2021/030201/junior-spring/AUTO3007`；同时涵盖学术型与专业型的研究生指南分别列出两个专业的课程页。这些修改在 hoa-blog 内容源完成。

新闻与生成的课程内容中，不限定具体培养方案的 `/docs/{学期}/{课程代码}` 旧引用改为 `/docs/{课程代码}`；例如 `https://hoa.moe/docs/junior-spring/auto3007/` 改为 `https://hoa.moe/docs/auto3007`。现有短链接会根据访问者的历史年级、专业或默认匹配结果跳转到具体页面；无 Cookie 时实测跳转到 `/docs/2024/030201/junior-spring/AUTO3007`。具体年级页面仍作为 canonical 和站点地图中的收录 URL。

`/docs` 入口可继续服务个性化跳转，但站点地图和搜索入口应直接使用稳定的年级 URL。只有确认需要让 `/docs` 本身作为搜索落地页时，再将其改为固定的年级导航页。

### 5. 完善与 URL 配套的页面信号

将根布局的 `lang="en"` 改为页面实际使用的中文语言标记；为博客、新闻列表页提供各自的标题和描述。检查课程页标题是否能让搜索用户区分课程与年级。标签页只有在提供有用的独立内容时才纳入站点地图；空页或价值低的筛选页不应仅为增加 URL 数量而收录。

## 验证与完成标准

1. 线上 `robots.txt` 允许公开页面抓取，`/sitemap.xml` 返回有效 XML，所有列出的 URL 均可直接返回 200。
2. 抽查首页、博客、新闻、课程和标签页的 canonical、页面标题、语言标记及内部链接；canonical 与站点地图不得相互冲突。以 `CHEM1018` 验证占位页有 `noindex` 且不在站点地图中，以 `AUTO3007` 验证有资料的课程页仍可收录；以 `/news/weekly`、一篇周报和 `/news/daily` 验证新闻排除规则，并确认其他新闻仍可收录。
3. 抽查已修复的内容链接，确认直接指向目标页面；旧博客地址不新增重定向，继续返回 404。
4. 在 Search Console 观察“已抓取但未编入索引”“重复网页”和规范网址选择情况，再决定是否扩大课程去重范围。收录与排名变化需要搜索引擎重新抓取后才能评估，不能仅凭部署成功判断。
5. 每项代码变更完成后执行仓库要求的 `make check`，并核对线上关键响应。
