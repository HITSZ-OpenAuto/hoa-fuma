### 课程内容

> 这门课程主要涉及肌电、超声等**生理信号**的原理、采集与处理，而非AI领域的多模态。

#### 1. 课程安排

| 序号 | 教学内容 |
| :---: | :--- |
| 1~2 | 总体介绍多模态与人机交互领域的研究。 |
| 3 | 仿生技术，主要包括仿生机械结构、传感器（视觉、触觉等）、算法（如遗传算法）三方面，以及在此基础上构建的仿生系统。 |
| 4 | 孤独症识别与诊断，包括行为、视觉等方面。 |
| 5 | 以四通道超声采集设备为例，介绍人机接口设备的设计与实现，以及超声信号的原理与处理方法。 |
| 6 | 肌电信号的产生原理、肌肉协同理论介绍。 |
| 7 | 肌电信号特征与处理（以手势识别系统为例）。 |
| 8 | 脑电信号及处理方法。 |
| 9 | 多传感器/多模态融合方法。 |
| 10 | 肌电动态手势识别实验，具体见“实验课程”。 |
| 11 | 脑电信号处理、脑肌耦合理论。 |
| 12 | 超声手势识别实验，具体见“实验课程”。 |

#### 2. 实验

| 序号 | 实验名称 | 实验内容 |
| :---: | :--- | :--- |
| 1 | 肌电动态手势识别实验 | 使用 16 通道肌电手环进行信号采集，对 4 类动态手势进行分类识别。实验涵盖数据采集、特征提取、SVM分类器、1D-CNN网络分类等环节，旨在掌握基于肌电信号的手势识别流程。 |
| 2 | 超声手势识别实验 | 使用 4 通道超声采集设备进行信号采集，对 8 类静态手势进行分类识别。旨在了解超声信号的原理、应用与基本处理方法。 |

### 关于考试

成绩构成：课堂表现20%，实验报告80%，无考试。
