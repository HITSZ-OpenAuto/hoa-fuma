## 人工智能安全

### 授课教师

- 罗文坚
  - 授课风格：不考勤，但上课时会与学生进行**巨量**互动。除讲课内容外，会穿插一些学术研究的思路。
  - 课程汇报时，老师和助教都会提问。
    > 文 / [345ljh](https://www.github.com/345ljh)，2026-09

### 课程内容

| 序号 | 教学内容 |
| :---: | :--- |
| 1 | 人工智能安全简介 |
| 2 | 对抗样本（攻防）：在数据添加扰动使模型功能异常 |
| 3 | 模型逆向：通过模型获取敏感训练数据信息 |
| 4 | 模型功能后门：对触发器输入功能异常，其他输入下正常 |
| 5 | 数据窃取后门：模型在训练过程中以隐蔽方式记录训练数据 |
| 6 | 成员和属性推理：分析数据样本是否用于训练数据模型 |
| 7 | 模型窃取：获取输入输出训练替代模型 |
| 8 | 深度伪造 |
| 9 | 提示注入与越狱 |
| 10 | RAG攻防 |
| 11 | 大模型幻觉缓解 |
| 12 | 深度学习攻防 |
| 13 | 分布式安全学习 |
| 14 | 智能体安全 |
| 15 | 人工智能公平与价值对齐 |
| 16 | 人工智能伦理与治理 |

### 关于考试

成绩构成：课堂汇报40%，期末报告60%，无考试。

- 课程汇报
  - 从第三次课开始，每次会安排1~2位学生在第2节进行汇报（顺序在课程开始就会发布）。一般大家会选取一两篇论文进行讲解。
  - 以下为助教原话：
    - 演讲主题为“人工智能安全”相关方向，同学们可结合自身兴趣选择相关论文或研究工作进行介绍，例如大模型安全、对抗攻击与防御、隐私保护、AI Agent 安全、内容安全、模型对齐、数据安全、生成式 AI 风险等方向。
    - 每位同学的汇报时间安排如下：**20分钟论文介绍与展示，10分钟课堂问答（Q&A）**。
    - 建议大家重点介绍：研究背景与问题定义，相关工作与研究动机，核心方法与技术路线，实验结果与效果分析，存在的问题与个人思考。
- 期末报告
  - 可采用论文、技术报告、实验报告、竞赛报告等形式，字数不少于 3000字。

> 文 / [345ljh](https://www.github.com/345ljh)，2026-09

## COMP5045 - 社交网络分析

### 授课教师

- 李旭涛
  - 授课风格：对于课程中涉及的算法与公式，多数会详细讲解与推导。
  - 考勤过一次。
    > 文 / [345ljh](https://www.github.com/345ljh)，2026-09

### 课程内容

| 序号 | 教学内容 |
| :---: | :--- |
| 1 | 社交网络的基本特征、随机图模型、小世界模型 |
| 2 | 社区划分的基本方法 |
| 3 | 重叠社区检测方法 |
| 4 | 人类评估与符号网络 |
| 5 | 网络的级联与传播模型 |
| 6 | 影响力最大化问题、Submodular（子模性）函数 |
| 7 | （信息、疾病等）爆发检测 |
| 8 | 图网络的幂律分布与优先连接 |
| 9 | 图网络随时间的演化 |
| 10 | Kronecker图 |
| 11 | 节点重要性评估，如HITS、PageRank |
| 12 | 同质与异质网络中的链接预测 |
| 13 | 社交网络的推荐问题 |
| 14 | 将网络节点映射到向量空间（网络嵌入Embedding） |
| 15 | 通过网络传播结果，反推网络的传播链 |

### 关于考试

成绩构成：出勤10%，汇报30%，考试60%。  

- 课程汇报
  - 1~3人一组，选取一个现有的社交网络数据集，使用课程所学的方法进行分析。  
  - 其中提交报告20%，课堂展示10%。  
  - 26春的汇报在考试后3天。  
- 期末考试  
  - 全开卷，试题全英文且使用英文作答。```note```文件夹仍放置了A4纸方便考试翻阅查找  
  - 考试以概念、原理为主（例如会要求写出某些算法的步骤、思想或公式），没有计算。
