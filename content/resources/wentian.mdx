## 获取方式

- **单份资料**：在上面的清单中点击下载即可。
- **整库克隆**：仓库包含约 120 MB 录播视频，完整克隆约 250 MB。网络不佳时建议只下载需要的文件，或使用浅克隆：

```bash
git clone --depth 1 https://gitee.com/jacobbbbb/lecturer-group.git
```

> Gitee 对大文件的 raw 直链会返回 403，因此站内镜像同时提供每个文件的下载直链。
